## Why this project

Taiwan's FSC leads FinLLM, a large language model for the financial industry; KGI takes part in data cleaning and model evaluation. A model learns from its data: if the data is wrong, the model learns the errors, and in finance an error can also break regulations. So every item is handled one by one; there is no shortcut.
