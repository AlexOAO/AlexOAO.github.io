## 結果

**貸款助理不需要任何 GPU：它在地端只用 CPU 做資料脫敏，成本會全部落在雲端 Token。** 業務量還在等 BU 提供，所以目前還算不出 TCO 與 ROI。

## 為什麼要做

貸款助理（Sales Agent）協助客戶申辦貸款。要把它和其他三個 Agent 放在同一個基準上比較，第一步是弄清楚它會用到哪些資源。

## 我的角色

我負責把貸款助理納入四大 Agent 的成本模型。

## 我怎麼做

**第一階段：確認地端元件。** 拆開來看，貸款助理在地端只有一個元件：用 CPU 做資料脫敏。所以它不占用 GPU 的空間池，成本可以直接套用雲端 Token 模型：業務量 × 每段旅程的 Token × 單價。

**第二階段：收回 BU 業務量。** 我已向 BU 索取每月的業務量，正在等回覆。

**第三階段：產出 TCO／ROI。** 業務量到齊後進行。

## 下一步

拿到業務量後，算出貸款助理的 TCO 與 ROI，放進四大 Agent 的比較表。
