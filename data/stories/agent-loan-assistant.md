## 為什麼要做

貸款助理（Sales Agent）協助客戶申辦貸款。要把它和其他三個 Agent 放在同一個基準上比較，第一步是搞清楚它會用到哪些資源。

## 我怎麼做

- **拆解地端元件**：貸款助理在地端只用 CPU 做資料脫敏，不需要 GPU 記憶體。
- **套用雲端 Token 模型**：成本＝業務量 × 每段旅程的 Token × 單價。
- **向 BU 索取月業務量**。

## 目前結果

貸款助理不占用 GPU 空間池，成本會集中在雲端 Token。月業務量還在等 BU 提供，所以目前還算不出成本與 ROI。

## 下一步

收到業務量後，計算 TCO 與 ROI，放進四大 Agent 的比較表。
