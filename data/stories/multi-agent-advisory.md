## 為什麼要做

一個人做投資決策容易有盲點，所以基金公司會設置不同角色的分析師。單一 LLM 也一樣：它很難同時處理技術面、新聞情緒與基本面，產出的建議也缺少可以檢驗的推理過程。如果讓 AI 像基金團隊一樣分工呢？

## 我的角色

我參與架構協作：設計 Multi-Agent 的分工，並整合 MCP 工具串接 TEJ 數據。

## 我怎麼做

### 五個 Agent，各司其職

- 技術分析師：計算技術指標，判斷趨勢。
- 新聞情緒分析師：取得即時新聞，量化市場情緒。
- 基本面分析師：分析財報數據，評估公司價值。
- 多空辯論員：整合以上觀點，進行正反辯論。
- 交易員：根據辯論結論，產出最終的買賣訊號。

### 為什麼用 LangGraph

和 CrewAI、AutoGen 比起來，LangGraph 給了更細的流程控制：Agent 之間的資料傳遞、條件分支、錯誤處理，都能用 Graph 清楚定義。在金融場景，「可控性」比「自主性」重要。

### 用 MCP 串接真實數據

透過 MCP，每個 Agent 都能直接呼叫 TEJ API 取得數據。系統不只是在聊天，而是根據數據做決策。

### 用回測驗證

最後把訊號接進 Zipline 回測引擎，在台股歷史資料上跑三年回測。具體績效不能公開，但結果讓團隊對這個架構的可行性有信心。

## 我學到的事

Multi-Agent 系統最大的挑戰，不是讓每個 Agent 變聰明，而是設計好它們之間的「溝通協議」：誰先說話、誰有最終決定權、衝突怎麼解決。這些流程設計決定了系統的上限。
